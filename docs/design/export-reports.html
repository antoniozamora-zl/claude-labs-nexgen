5. Flujo de usuario

User flow

  1. Usuario navega a /reportes desde la barra de navegacion
  2. Selecciona tipo de reporte (Ordenes o Ventas)
  3. Selecciona rango de fechas (inicio y fin)
  4. Click en "Generar preview" — se muestra tabla con datos y tarjetas de resumen
  5. Si no hay datos: empty state con mensaje, sin boton de descarga
  6. Si hay datos: click en "Descargar PDF" — se genera y descarga el archivo
  7. Mientras genera: boton muestra estado de carga "Generando..."
  8. PDF descargado incluye header con branding, tabla de datos y resumen

6. Componentes requeridos

Arquitectura de componentes

  • src/pages/ReportsPage.jsx — Pagina principal con filtros y preview
  • src/components/ReportFilters.jsx — Filtros: tipo, fecha inicio, fecha fin
  • src/components/ReportSummary.jsx — Tarjetas de resumen (total, ingreso, promedio)
  • src/components/ReportTable.jsx — Tabla de preview con datos
  • src/components/EmptyState.jsx — Estado vacio reutilizable
  • src/services/pdfGenerator.js — Logica de generacion de PDF con pdfmake
  • src/data/mockData.js — Datos mock de ordenes y ventas
  • src/utils/dateFormatter.js — Formateo DD/MM/YYYY
